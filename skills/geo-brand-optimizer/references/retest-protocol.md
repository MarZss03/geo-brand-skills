# Comparable retest protocol

1. Preserve the baseline evidence file and query set.
2. Record deployed changes, URLs, and dates.
3. Allow the chosen discovery/indexing window to pass; state the assumption rather than claiming a universal waiting period.
4. Repeat the same queries, engines/models, locale, and collection method where possible.
5. Keep all valid runs and label unavoidable model or interface changes.
6. Compare mention rate, citation rate, answer fit, and recurring sources with raw numerators and denominators.
7. Classify each hypothesis as supported, not supported, or inconclusive. Do not convert a correlation into a guarantee.
