# Reproducible audit methodology

## Query design

- Derive questions from real buyer or evaluator tasks.
- Keep the baseline query set unchanged for follow-up tests.
- Balance broad discovery queries with specific comparison and verification queries.
- Avoid leading prompts that force the target brand into the answer except in the branded-verification group.

## Sampling

Run the same query more than once when time permits because answers vary. Keep every valid result. Record login state or personalization limits when known, but never copy credentials into the dataset.

## Interpretation

Use denominators and sample sizes beside percentages. A result from 3 queries should not be framed with the certainty of 100. Compare engines descriptively unless collection conditions are equivalent. Correlation between a site change and a later answer change is not proof of causation.
