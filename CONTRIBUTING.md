# Contributing

Issues and pull requests are welcome, especially for reproducibility problems, misleading claims, accessibility, new evidence formats, and tested examples.

Before submitting:

1. Keep observations, inferences, and recommendations separate.
2. Do not add private data, model credentials, or copyrighted answer dumps.
3. Run both example commands in the README.
4. Validate each changed skill with the skill-creator validator.
5. Explain the problem, expected behavior, and test evidence in the pull request.
